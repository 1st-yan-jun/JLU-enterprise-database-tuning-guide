## 四、推荐使用流程

1. **搭环境**：装好 Windows XP + DB2 9 Express-C，用「第一步（First Steps）」建出 `SAMPLE` 库；确认 `DB2 - DB2COPY1 - DB2` 服务已启动，并把当前账户加入 `Administrators` 与 `DB2ADMNS` 组（详见报告 1 指南的 1.1–1.3 节）。
2. **读课件**：打开对应 Unit 的 PPT，确认本次实验要交哪几道题、截图有什么要求。
3. **照着做**：打开同名「操作指南文档」，从环境准备读到最后一题，命令可整段复制进 `db2cmd`；每完成一题按「截屏要点」截图。
4. **对照成品**：做完后打开 `word结果/` 里的报告，核对图号顺序、文字解答是否齐全、表格是否填写完整。
5. **提交**：导出 PDF 存到 `结果演示/`，按「学号_姓名_实验项目」规范命名。

## 五、实验中的关键约定（易踩坑）

* **数据库命名**：报告 1 只用系统自带的 `SAMPLE` 库，**不要**新建以学号命名的库；报告 2 起必须新建 `lzb_1019`，课件模板里的 `MUSICDB` 不得直接使用。
* **截图身份**：所有截图中虚拟机标签、Windows 账户、DB2 授权标识都要是自己的标识（`lzb_1019`，8 个字符以内），**严禁残留他人的姓名/账户名**（历史报告里出现过 `yan_jun`，被判为抄袭风险）。
* **图文并茂**：每道题除截图外必须补文字解答与结果分析，不能只贴图。
* **脚本工作目录**：`LabFiles` 里的脚本大量使用相对路径，务必先 `cd` 到 `Labfiles\CF23` 再执行，并注意脚本的换行符与 `db2 -tvf` 的区别。
* **常见报错**：`SET INTEGRITY PENDING` 状态的解除、`LOAD` 与 `IMPORT` 对触发器/约束的不同影响、`SQL0911N` 是锁超时还是死锁——报告 4/5/6 指南附录里都有对症说明。
